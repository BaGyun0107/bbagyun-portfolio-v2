## 구현 사실 계약

### Core Product

- `Products`를 공통 상품 부모로 두고 객실·관광 세부 모델을 연결했다.
- 주문 항목은 공통 `productId`를 참조한다.
- 객실의 날짜별 재고는 객실과 객실 옵션을 직접 참조한다.
- 목적은 객실·관광을 한 주문·결제 구조에서 처리하고 재고 조회 경로를 짧게 유지하는 데 한정한다.

### 재고 충돌

- 재고 `version`을 갱신 조건에 포함하고 갱신 건수가 0이면 충돌로 처리했다.
- 정상·충돌 분기를 단위 테스트로 확인했다는 내용은 사용자 보고값으로 표시한다.
- 현재 원본 `dev` 코드에서 확인된 `version + updateMany` 구현과 성공 분기 테스트를 충돌 분기 테스트의 코드 증거로 바꾸지 않는다.

### 결제 경계

- 주문·재고 사전 기록, 외부 PG 승인, 주문·결제 확정은 서로 다른 단계다.
- 최종 내부 확정 실패 시 PG 취소를 시도한 구현을 공개한다.
- PG 승인 실패 시 주문 `CANCELLED`, 결제 이력 `ABORTED`로 기록하지만 차감 재고의 즉시 복구는 보류 시점에 미완성이었다고 밝힌다.

### BFF·Cloudflare

- 실제 주소 대신 프론트엔드 `A-domain.com`, API `api.A-domain.com`을 사용한다.
- 두 주소는 같은 기본 도메인의 서로 다른 Origin이다.
- 브라우저 직접 API 호출에서 쿠키 저장·전달 실패를 확인한 뒤 Next.js `/bff` rewrite로 브라우저 Origin을 통일했다.
- 구현은 reverse proxy로 BFF 경계를 만든 단계이며 완성형 BFF라고 부르지 않는다.
- 이후 서버 요청의 Cloudflare 봇 차단을 확인하고 BFF 서버의 고정 IP를 허용 규칙에 등록해 스테이징 통신·인증을 복구했다.

## 결과와 미완성 범위 계약

고객사는 스테이징에서 다음 핵심 흐름을 직접 확인하거나 UAT로 검증했다.

```text
행사 생성
→ 호텔·객실·재고 등록
→ 사용자 객실 조회·예약·PG 테스트 결제
→ 관리자 예약 확인·취소
```

- 정식 운영과 실제 운영 결제는 없다.
- 관광 예약, 결제 링크, 일부 엑셀 다운로드와 문서 템플릿은 미완성이다.
- 핵심 객실 흐름 UAT를 전체 기능 완성이나 운영 성과로 확대하지 않는다.

## 회고 계약

- 외부 결제가 끼는 흐름은 실패 지점별 상태 전이·보상·재시도·운영자 확인 절차를 함께 설계해야 한다.
- 재고 충돌은 실제 데이터베이스 병렬 요청을 포함한 통합 테스트가 필요하다.
- 인증은 Global Auth Guard를 기본 적용하고 공개 경로만 제외하며 관리자 등급을 별도 권한 Guard로 분리하는 방향을 현재 개선 판단으로 제시한다.
- 위 항목은 당시 완성한 성과가 아니라 보류 이후의 회고다.

## 금지 주장과 비공개 정보

다음은 작업물과 연결 인사이트에서 사용자의 실제 성과나 검증 결과로 나타나면 안 된다.

- 고객사의 구체적인 자금 사정
- 실제 회사 도메인·서버 IP·고객 거래 데이터·인증값·시크릿·비공개 소스
- `JOIN Depth 5단계 이상 → 최대 3단계` 또는 다른 JOIN 단계 수치
- 임의 상품을 하위 테이블 하나만으로 무변경 확장한다는 보장
- 실제 DB 병렬 통합 테스트 완료, 불일치 0건, 초과 예약 완전 방지와 운영 정합성
- 예약·결제·재고를 한 DB 트랜잭션으로 묶었다는 주장
- 고아 재고 0건 또는 완성된 결제 보상 흐름
- 응답 조합·프론트 전용 권한·가공·성능 개선을 갖춘 완성형 BFF
- 전 환경 정상화, 운영 장애 해결, 운영 건수·장애율·성능·전환율
- Middleware가 Guard보다 항상 견고하거나 인증 선언 누락을 완전히 제거했다는 주장
- 비밀번호 암호화 제거를 모든 클라이언트 AES 제거로 확대하는 주장

## 연결 계약

- 작업물의 관련 인사이트 영역에는 canonical 인사이트 3개만 한 번씩 나타난다.
- 각 인사이트는 작업물로 돌아가는 `연관된 기록` 링크를 제공한다.
- 보이는 링크 이름은 연결 대상과 맥락을 설명하고 keyboard Enter로 활성화된다.
- alias BFF 글은 작업물 관련 글 개수에 포함하지 않는다.
