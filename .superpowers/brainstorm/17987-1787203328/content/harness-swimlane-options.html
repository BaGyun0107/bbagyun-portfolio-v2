하나의 긴 흐름

개발 시작부터 배포까지 한 장에 담습니다. 전체 흐름은 빠르게 보이지만 정책·개발·배포의 목적이 섞여 모바일에서 밀도가 높아집니다.

핵심 책임을 두 흐름으로 분리

개발 운영과 배포 운영을 분리해 각 다이어그램이 하나의 질문에 답합니다. 본문 길이와 모바일 가독성의 균형이 가장 좋습니다.

권장안 B의 장점

  • 두 그림이 각각 하나의 책임만 설명
  • 모바일 내부 스크롤 범위를 짧게 유지
  • 다른 작업물에도 동일한 선택형 계약 재사용 가능
