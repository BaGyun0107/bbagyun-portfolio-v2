case study anatomy

한 작업물을 읽는 방식

골프 예약 시스템 구축프로젝트 개요문제 상황설계 의사결정아키텍처 흐름ERD / API결과와 회고

외부 예약 API의 변동성을 내부 도메인에서 격리했습니다.

소스코드를 공개하지 않아도 어떤 문제를 만났고, 어떤 대안을 비교했으며, 왜 현재 구조를 선택했는지 확인할 수 있도록 구성합니다.

시퀀스 다이어그램정상 흐름과 외부 연동 실패를 한 화면에서 확인
예약 도메인 ERDReservation과 Attempt를 분리한 데이터 책임
API 계약내부 상태와 provider payload의 adapter 경계
운영 증거timeout, rejection, retry를 구분하는 로그
